# Odin Recipes

## About
This project is part of The Odin Project's Foundations course. It is a basic multi-page recipe website built entirely with semantic HTML to practice core web development fundamentals, structure documents properly, and link pages together. 

## Skills Demonstrated
* Structuring HTML5 documents with proper boilerplate and metadata.
* Organizing project files and directories cleanly (root index linked to sub-folder recipe pages).
* Utilizing headings (`<h1>`, `<h2>`), paragraphs (`<p>`), unordered and ordered lists (`<ul>`, `<ol>`, `<li>`), and anchor tags (`<a>`) for navigation.
* Managing version control locally using Git (staging, branching, and commit history).

## Contents
* `index.html`: Homepage featuring navigation links to the custom recipes.
* `recipes/sandwich.html`: Recipe for a thick-toasted Gouda and egg melt.
* `recipes/drinks.html`: Recipe for the sandwich that feels right, a soul-warming dark coffee or strong black tea that makes you feel like it is hugging you from the inside, paired with a cold milk finisher.
